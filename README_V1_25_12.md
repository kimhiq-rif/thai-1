# Thai Trainer v1.25.12

## Level 5.5 - Guided Chat Bot Board

- Added Level 5.5 to the level selector.
- The board becomes an active guided chat instead of the handwriting canvas.
- The bot asks in English transliteration.
- The student answers by typing Thai script.
- If the answer is understood, the conversation continues.
- If the answer is unclear, the bot asks what the student meant in Hebrew or English, gives a correction, then continues.
- Includes three starter topics: introductions, food, and travel.

## Notes

- This first version uses stable local rule-based understanding.
- It is ready to be upgraded later to a full AI chat engine.
