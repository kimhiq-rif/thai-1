# Thai Trainer Web App v1.8 — Writing Vowel Board + User Tabs

## מה חדש

- רמה 6 הוחלפה ממצב אמריקאי למצב **כתיבה**.
- לוח התנועות הורחב וכולל סימנים רבים מהפוסטר, כולל שמות הסימנים, מילת לוח, משמעות, צליל, אימוג׳י והערת כתיבה.
- נוספה תמיכה ב־**עברית / English** בממשק ובשאלות.
- נוסף שדה **שם משתמש**. לאחר כתיבת שם ולחיצה על Enter, הסקריפט יוצר/מוצא לשונית משתמש בגוגל שיטס.
- כפתור **שמור התקדמות** שומר את ההתקדמות ללשונית של המשתמש.
- `google_apps_script.gs` עודכן לגרסה v1.8: קובץ Google Sheet מרכזי + לשונית נפרדת לכל משתמש.
- שדרוג ויזואלי: כרטיסים מודרניים יותר, אזור כתיבה ברור יותר, התאמה טובה יותר למובייל וטאבלט.

## איך לעדכן ב־GitHub/Vercel

1. החלף את קבצי הפרויקט בקבצים שבתיקייה הזו.
2. העתק את `google_apps_script.gs` לתוך Apps Script של Google Sheet שלך.
3. Deploy מחדש כ־Web App עם:
   - Execute as: Me
   - Who has access: Anyone
4. העתק את כתובת ה־Web App לאפליקציה.
5. הקלד שם משתמש ולחץ Enter.
6. בסיום תרגול לחץ **שמור התקדמות**.

## הערת תאימות

הקוד משתמש ב־Pointer Events עבור כתיבה בקנבס, ולכן מיועד לעבוד במחשב, iPad, iPhone ו־Android. לא בוצעה בדיקה פיזית על כל מכשיר; מומלץ לבדוק אחרי הפריסה על המכשירים שלך.
