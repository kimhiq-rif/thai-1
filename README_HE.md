# Thai Trainer Web App v1.11 — Writing Vowel Board + User Tabs

## מה חדש

- רמה 6 הוחלפה ממצב אמריקאי למצב **כתיבה**.
- לוח התנועות הורחב וכולל סימנים רבים מהפוסטר, כולל שמות הסימנים, מילת לוח, משמעות, צליל, אימוג׳י והערת כתיבה.
- נוספה תמיכה ב־**עברית / English** בממשק ובשאלות.
- נוסף שדה **שם משתמש**. לאחר כתיבת שם ולחיצה על Enter, הסקריפט יוצר/מוצא לשונית משתמש בגוגל שיטס.
- כפתור **שמור התקדמות** שומר את ההתקדמות ללשונית של המשתמש.
- `google_apps_script.gs` עודכן לגרסה v1.11: קובץ Google Sheet מרכזי + לשונית נפרדת לכל משתמש.
- שדרוג ויזואלי: כרטיסים מודרניים יותר, אזור כתיבה ברור יותר, התאמה טובה יותר למובייל וטאבלט.

## איך לעדכן ב־GitHub/Vercel

1. החלף את קבצי הפרויקט בקבצים שבתיקייה הזו.
2. העתק את `google_apps_script.gs` לתוך Apps Script של Google Sheet שלך.
3. Deploy מחדש כ־Web App עם:
   - Execute as: Me
   - Who has access: Anyone
4. העתק את כתובת ה־Web App לאפליקציה.
5. הקלד שם משתמש ולחץ Enter.
6. בסיום תרגול לחץ **שמור התקדמות**.

## v1.20 — תיקון מידע בלחיצה על אות/סימן

- בלחיצה על אות תאית מוצג עכשיו גם תעתיק שם האות, למשל `หอ หีบ (ho hiip / ho hib)`.
- מוצגת גם מילת הלוח עם תעתיק + עברית + אנגלית.
- נוספה הערה מיוחדת ל־`ห` על `ห นำ`, למשל במילה `หลง` — ה־h לרוב לא נהגית אלא משפיעה על הטון.
- בלחיצה על סימני תנועה/טון מוצג עכשיו גם תעתיק שם הסימן, למשל `ไม้ไต่คู้ (mai taikhu)`.
- כללי הסימנים מופיעים עכשיו בעברית בממשק עברי ובאנגלית בממשק אנגלי.
- דוח בדיקה נוסף: `data/click_info_audit.csv`.

## v1.22 — תיקון/אבחון סנכרון Google Apps Script

- נוסף כפתור בדוק חיבור שמריץ ping מול ה-Web App.
- נוסף כפתור פתח בדיקה שפותח את כתובת ה-ping בלשונית חדשה.
- כתובת ללא `/exec` מתוקנת אוטומטית.
- כתובת `/dev` מוחלפת אוטומטית ל-`/exec`.
- הודעת `script load failed` עכשיו מסבירה שלרוב מדובר בחסימה של VPN / AdBlock / Tracking Protection / דפדפן.

אם בלשונית החדשה מופיע JSON עם `ok:true`, הסקריפט תקין והבעיה היא חסימת דפדפן. במקרה כזה נסה Chrome/Safari או כיבוי VPN/חוסם פרסומות.
