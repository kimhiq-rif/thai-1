# Thai Trainer — הוראות הפעלה

## פתיחה מקומית לבדיקה
פתח את `index.html` בדפדפן במחשב.
באייפון מומלץ לא לפתוח כקובץ מקומי, אלא להעלות את התיקייה ל־Vercel / Netlify / GitHub Pages.

## פריסה כ־Web App
הדרך הכי פשוטה:
1. פתח חשבון ב־Vercel.
2. העלה את התיקייה כפרויקט סטטי.
3. קבל לינק קבוע.
4. פתח אותו באייפון/אייפד/PC.
5. באייפון: Share → Add to Home Screen.

## סנכרון Google Sheets
1. פתח Google Sheet חדש.
2. Extensions → Apps Script.
3. הדבק את הקובץ `google_apps_script.gs`.
4. Deploy → New deployment → Web app.
5. Execute as: Me.
6. Who has access: Anyone with the link.
7. העתק את כתובת ה־Web App לתיבת הסנכרון בתוך האפליקציה.

## מה נבדק אוטומטית
- 5 רמות קיימות.
- בכל רמה לפחות 50 וריאציות שאלות.
- אין מזהים כפולים.
- לכל פריט יש תאית, תעתיק, עברית וטון.
- כל טון שייך לרשימת הטונים הנתמכת.

## הערה חשובה
בדיקת שפה אנושית עדיין חשובה. המערכת כוללת בדיקות מבניות, אבל לפני הרחבה גדולה של אוצר מילים כדאי לעבור ידנית על תרגום וטונים.
