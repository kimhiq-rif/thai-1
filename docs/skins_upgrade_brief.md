## איפה הכל נמצא (קרא לפני שתתחיל)

- **THEMES**: `app.js` ~1299–1315
- **applyTheme()**: `app.js` ~1526 — מוסיף `body.theme-<id>`. כאן מוסיפים מצב light/dark ומפעילים אנימציית כניסה.
- **currentTheme()**: `app.js` ~1525
- **CSS של הסקינים**: `styles.css` ~248–280 — פלטת משתנים (`--bg/--panel/--panel2/--text/--muted/--blue/--blue2/--green/--red/--orange/--border`) + גרדיאנט רקע + מוטיב SVG מרוצף ב־`::before` (שקיפות ~0.16).
- **מנוע אפקטים קיים**: `lib/juice.js` — API: `Juice.init/correct/win/setSound`. חלקיקים + צליל (WebAudio) + haptics כבר עובדים.
  - hooks של "צדקתי": `app.js` ~1477, ~2822, ~3190 (`Juice.correct(...)`)
  - hooks של סיום אתגר: `app.js` ~1943, ~2860 (`Juice.win()`)
- **בורר סקינים (UI)**: `app.js` ~3254–3264 (כפתורי `.skin-card`)
- **טעינת קבצים**: `index.html` שורה ~14 (CSS), ~233–236 (JS). בדוק את ה־`?v` הנוכחי לפני פריסה.
- **reduced-motion**: הפונקציה `reduced()` ב־`lib/juice.js` — חקה אותה.
- **נכסים**: `assets/` — שים ארט חדש ב־`assets/skins/<id>/`.

מספרי השורות משוערים — אמת עם חיפוש טקסטואלי, הקוד זז.

## מה לבנות לכל סקין — 6 רכיבים

1. **פלטה כפולה**: מצב מוחשך (קיים — שדרג) + מצב מואר חדש. שני המצבים דורסים את אותם משתני CSS.
2. **דמות/מנטור**: PNG/WebP שקוף ב־`assets/skins/<id>/`. מופיעה בכניסה ובחגיגת סיום אתגר. ראה מפת דמויות למטה.
3. **אנימציית כניסה**: מופעלת מ־`applyTheme()` כשעוברים לסקין. ~1.2–2 שניות, לא חוסמת אינטראקציה.
4. **אפקט "צדקתי" ממותג**: צבע + מוטיב תואם־theme במקום הניצוצות הגנריות. העבר פלטת theme ל־`Juice.correct`.
5. **קליימקס סיום אתגר**: סינמטיק מלא־מסך תואם־theme + הדמות חוגגת. הרחב את `Juice.win`.
6. **(coral/festival/master בלבד) רקע אמביינט חי**: canvas/WebGL עדין מאחורי התוכן.

**נכסים**: PNG/WebP שקוף, 2 גדלים (512 + 1024 רוחב), אופטימיזציה למובייל. שמות: `assets/skins/<id>/character.webp`, `entrance.webp` וכו'.

## ארכיטקטורת light/dark (השינוי המבני היחיד — בנה קודם)

- הוסף `state.prefs.skinMode` (`'dark'|'light'`), ברירת מחדל `'dark'`.
- ב־`applyTheme()`: הוסף/הסר `body.mode-light` לצד `body.theme-<id>`.
- כפתור toggle: חקה בדיוק את התבנית של `#sfxToggle` + `state.prefs.sfx` (חפש אותם ב־`app.js`).
- ב־CSS: `body.theme-royal{...}` = מוחשך (קיים). הוסף `body.theme-royal.mode-light{...}` = מואר. כך לכל 6.
- מצב מואר חייב לשמור על ניגודיות קריאה — לא היפוך נאיבי; פלטה מוארת מעוצבת לכל סקין.

## מודול חדש: `lib/skins-fx.js`

- אחראי על אנימציות כניסה + רקע אמביינט per-theme. טען ב־`index.html` עם `defer` + `?v`.
- API מוצע: `SkinsFX.enter(themeId)`, `SkinsFX.ambient(themeId)`, `SkinsFX.stop()`.
- קרא ל־`SkinsFX.enter()` מתוך `applyTheme()`. השתמש ב־`requestAnimationFrame`; נקה בין החלפות סקין.
- מנף את שכבת ה־canvas של `juice.js` או צור overlay משלך (`pointer-events:none`, z-index מעל הרקע ומתחת ל־UI).

## אילוצים (חובה)

1. **Vanilla JS בלבד.** אין npm/framework/build. קוד חדש = `<script>`/`<style>` רגיל.
2. **כבד `prefers-reduced-motion`**: תמיד ספק fallback סטטי (בלי אנימציה) — חקה `reduced()` מ־`juice.js`.
3. **אל תשבור את Juice הגנרי הקיים** — בנה מעליו, לא במקומו. סקינים שלא שודרגו ממשיכים לקבל את האפקט הגנרי.
4. **ביצועים**: מובייל/iPhone הוא היעד. רקעים חיים חייבים להיות קלים; עצור אמביינט כשהטאב לא פעיל (`visibilitychange`).
5. **אל תיגע ב־`sw.js`** (service worker שמבטל את עצמו — אין caching לדאוג לו).
6. **משתני ה־CSS הקיימים הם חוזה**: קומפוננטות קוראות דרך `--bg/--panel/--text/--blue/--border`. מצב מואר דורס אותם, לא עוקף.
7. **בטיחות לימודית**: כל טקסט תאי שמוצג (גם בדמויות/ארט) מלווה בתעתיק + עברית + אנגלית, או שהוא דקורטיבי בלבד.
