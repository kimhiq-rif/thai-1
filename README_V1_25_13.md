# Thai Trainer v1.25.13

## Level 5.5 - Transliteration Chat Mode

- Added a second writing mode inside Level 5.5.
- Students can now choose between Thai-script answers and transliteration-only answers.
- Transliteration mode lets the student practice vocabulary and sentence structure without typing Thai script.
- The guided bot still asks in transliteration and continues the conversation when intent is clear.
- If the answer is unclear, the bot asks for the intended meaning in Hebrew or English, suggests a corrected transliteration, then continues.
